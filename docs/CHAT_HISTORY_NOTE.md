# About the conversation history

This handoff packages the **artifacts** and a carefully written **decision/context summary** from the ChatGPT conversation. It does **not** import the original ChatGPT conversation as a Codex chat, does **not** contain a complete verbatim ChatGPT transcript, and does not preserve past ChatGPT message attachments as separate Codex chat attachments. The canonical narrative and research content is included in docs, and source images are retained in archives.

For an exact historical transcript, keep the original ChatGPT conversation accessible in ChatGPT; if desired, use ChatGPT's account data export mechanism to archive your chat history separately. Codex can read an exported transcript file if you subsequently put it in this project folder, but that is **reference material**, not restored Codex conversation history. Avoid checking private chat/account exports into a public source repository.
